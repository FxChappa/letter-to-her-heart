# Letter to Her Heart

Santana’s private, mobile-first interactive love letter from Aldane, built with React, TypeScript, and Vite.

## Experience

- Elegant chapter-based reading flow
- Responsive design tuned for mobile phones
- Restrained ambient motion and scroll reveals
- Original browser-generated instrumental soundscape
- Sound toggle and volume control
- Reading progress indicator
- Accessibility and reduced-motion support
- Vercel-ready with no environment variables

## Run locally

```bash
npm install
npm run dev
```

## Production check

```bash
npm run build
npm run preview
```

## Deploy to Vercel

1. Keep the GitHub repository **private**, because the complete personal letter is stored in the source.
2. In Vercel, select **Add New → Project**.
3. Import `letter-to-her-heart`.
4. Vercel will detect Vite automatically.
5. Select **Deploy**.

No environment variables are required.
